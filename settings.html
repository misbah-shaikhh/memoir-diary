About This Project

This online diary web app allows users to log in and save their notes, manage them by archiving or deleting, and even mark them as favorites. The app features a clean, intuitive interface with the option to switch between light and dark themes. Built using Node.js, Express, and MongoDB for the backend, the app offers secure authentication and stores user data like bio and mood. The front-end is designed with HTML, CSS, and JavaScript to ensure a responsive and user-friendly experience. This simple yet powerful tool is perfect for capturing thoughts, staying organized, and exploring creativity, all while keeping things private and easy to manage.
